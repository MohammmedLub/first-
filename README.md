# Functional Analyst Portfolio

This repository contains a static website that showcases the professional portfolio of **Mohammed Lubbad**, a business and IT professional specialising in functional analysis, requirements gathering, testing and process optimisation.

## How to use

1. **Clone or download** this repository to your local machine.
2. Open `index.html` in your web browser to view the portfolio offline.
3. **Customise** the content by editing `index.html` – update the about section, project descriptions, contact details or images to reflect your own work and story.
4. To **deploy** the site on GitHub Pages:
   - Create a repository named `<username>.github.io` or enable GitHub Pages in the repository settings and set the source to the `master` branch.
   - Commit and push the files to your GitHub repository.
   - GitHub will host the site at `https://<username>.github.io` automatically.

## Structure

The project files are organised as follows:

- `index.html` – The main webpage containing the portfolio content.
- `css/style.css` – The stylesheet that defines the look and feel of the site.
- `hero-bg.jpg` – Decorative background image used in the hero section. You can replace this with your own image.
- `README.md` – This file, providing instructions and information about the project.

## Customisation

Feel free to modify the content, styles and structure to better suit your personal story and professional experiences. You can:

- Replace `hero-bg.jpg` with your own graphic or photograph.
- Adjust the colours and fonts in `css/style.css`.
- Add or remove sections, such as additional projects or skill listings.
- Update the contact information with your real email address and social links.
